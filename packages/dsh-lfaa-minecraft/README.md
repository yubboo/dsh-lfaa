# dsh-lfaa-minecraft

Minecraft Host domain owned by DSH-LFAA. It currently supports Paper and Fabric. Paper versions/builds come from PaperMC and server JARs are verified against the publisher's SHA-256. Fabric versions, stable loaders/installers, and the server bootstrap JAR come from Fabric Meta. That endpoint does not publish the same expected-size/checksum metadata, so the plugin caps the download, validates JAR format, and records the locally computed hash without claiming publisher-checksum verification. Both distributions use Mojang Java metadata and can install a compatible Temurin JRE through the official Adoptium API with checksum verification. The package exposes the `minecraft_server` DSH Agent tool so the model chooses each next step from real tool results.

The caller supplies an absolute writable data root for each operation. Instance files live under `dsh-lfaa/minecraft/instances/<id>` and plugin-installed runtimes under `dsh-lfaa/minecraft/runtimes/`. If compatible Java is missing, the model can inspect first and then call `install_java`; the service accepts only Adoptium release metadata and Temurin release assets and verifies the published SHA-256 before extraction. The service refuses to start until the user explicitly accepts the Minecraft EULA.

The model uses `minecraft_server` in sequence for distribution/version/build discovery, Java inspection/installation, instance creation, server installation, and lifecycle actions. Installation and startup are separate operations, and the model must inspect each result before choosing the next action. Downloads, writes, console commands, and process actions follow DSH sandbox policy; denial or cancellation ends the flow. The Paper/Fabric session panel is connected to the current DSH Session. Fabric mods can be searched through Modrinth by game version, then installed with required dependencies into a stopped Fabric server and verified against SHA-512 metadata. Tool registration, invocation and approval behavior in a real DSH Profile remain unverified; modpacks and Forge/NeoForge adapters are future work.
