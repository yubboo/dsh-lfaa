# dsh-lfaa-appearance

English | [中文](README.zh.md)

Private appearance capability owner. The config export supplies the Host schema: enabled=true, preset=native, density=comfortable, motion=system. The default export path provides browser-safe token derivation and lifecycle registration; it imports no Host database/credentials code.

DSH validates/persists Profile values and ConfigForms projects them to consumers. Optional light/dark token layers are reversible; disabled/unavailable values restore lower layers, identical echoes do not restack, OS reduced motion wins and listeners dispose. No navigation, model request or account storage lives here. Tests assert behavior and cleanup; root build inlines this implementation into the installable plugin.
