# dsh-lfaa-appearance

[English](README.md) | 中文

私有外观能力 Owner，config 导出 Host schema：enabled=true、preset=native、density=comfortable、motion=system；默认路径提供浏览器安全的令牌投影和生命周期登记，不引入 Host 数据库/凭据代码。

DSH 校验/保存 Profile 配置并由 ConfigForms 映射；浅深令牌层可撤销，关闭/不可用恢复下层，相同回声不重叠，系统减少动态效果优先且监听清理。不拥有导航、模型请求或账号存储。测试覆盖行为与清理，根构建内联到可安装插件。
